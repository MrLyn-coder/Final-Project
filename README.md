# Final-Project
Repository Description
Cloud-native AI automation platform for SMEs using Azure, Terraform, n8n, and OpenAI GPT-4o. Demonstrates intelligent workflow automation, infrastructure-as-code deployment, and AI-powered business process orchestration.

Repository About Section

Building a cloud-native, AI-augmented automation system for Small and Medium-sized Enterprises (SMEs) using Microsoft Azure, Terraform, n8n, and OpenAI GPT-4o.

Key Features
Infrastructure-as-Code deployment with Terraform
Cloud-native workflow orchestration using n8n
AI-powered business automation with GPT-4o
Customer enquiry automation
Inventory reorder prediction
Sales pipeline management
Financial reporting automation
Azure monitoring and observability
SME-focused architecture and cost optimisation
Technology Stack
Microsoft Azure
Terraform
n8n
OpenAI GPT-4o
Azure Monitor
Application Insights
Azure App Services
Azure SQL Database
Research Objective

To evaluate whether SMEs with limited IT resources can successfully build, deploy, and sustain intelligent cloud-based automation systems using modern low-code and AI technologies
